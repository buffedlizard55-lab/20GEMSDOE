# Ranked geological hypotheses — prospective H22 family (2026-10-01)

**Read before implementing.** OBSERVED = linked source statement; COMPUTED = named artifact; INFERENCE = proposed test. None of these ideas has demonstrated hidden-test DTI improvement. Expected gains below are **subjective upside scenarios**, not measured effects, confidence intervals or predictions. The fixed family has five entries; unavailable ideas are not quietly removed from the multiple-testing denominator.

## Audit correction and ranking rationale

The previous register incorrectly called demagnetization a new physical mechanism. H16-4 already has `hydro_demag_conduit` (negative local RTP × magnetic gradient × non-playa mask), and 15GEMSDOE tried alteration/magnetics (reported 0.0782). **H22-2 is only an untried geometry/polarity ablation**, not a wholly new geological idea. It is run first to finish the previous session's explicit queue at low cost; it is not represented as our contrarian breakthrough. Novelty beyond code and archived descriptions actually inspected is unverified.

The strongest genuinely different *local-data* research direction is H22-3: **displacement of an independently visible marker**, not finding another generic ridge. H22-1 has a distinct physical observation but only 21 volcanic vents. Landsat and drainage proposals are **not executable/viable yet**: free access is documented, but actual footprint coverage/quality and download access must pass QA before their preregistered execution. No leaderboard forecast can responsibly rank these from the present evidence.

## Statistical structure and research gates

- Catalogue zeros are **unlabeled**, not verified absence. The official description also warns catalogue positives may be inaccurate. PU is a defensible working formulation; exact nnPU assumptions (representative positives, mixture sampling, a class prior) still need testing. It is **not proven** that a PU blind spot caused the historical scores; artifact duplication already explains some repeated scores.
- The previous H20 tree-weight/pseudo-label scheme is not the Kiryo risk objective. Sampling only `S=0` also differs from Kiryo's marginal `X` sample. New risk code must explicitly handle the distinction and a representative-positive assumption; labeling propensity cannot be invented from scarp scores.
- Power-law undercount is a **scenario prior**, not a measurement. Fit official vector trace lengths and disclose segmentation, completeness cutoff, lower truncation, uncertainty and conversion to pixels. A high log-log R² alone is not a goodness-of-fit test.
- Known-catalogue spatial holdouts and synthetic thinning are development proxies only. No used quadrant/old H20 Vault is untouched; a new subset of already inspected outcomes does not restore blindness.
- The five H22 candidates form one fixed family. Pending tests carry p=1. Apply Holm FWER 0.05; report BH FDR only descriptively. One-sided block sign-flip p-values with four folds have minimum 0.0625, and adjacency/exchangeability is unverified. No statistical promotion can be claimed from these four folds.
- Recommend no slot without a reproducible improvement, effective-prediction uniqueness, format checks and **one globally single-use independent final confirmation**. New independently adjudicated fault/background labels are presently unavailable. Never manufacture them from the model or mark unlabeled pixels as verified negatives for calibration.

Sources are claims about their own settings/data, not proof of these operators or DTI gains. The target is **fault geometry useful for geothermal exploration**, not directly identifying geothermal vents or guaranteeing a productive reservoir.
